# Web Development Templates

A collection of reusable web development components, interactive UI elements, animations, and visual effects built with HTML, CSS, JavaScript, and jQuery.

This project demonstrates different frontend development techniques through practical examples of navigation menus, image galleries, animated headers, SVG graphics, parallax effects, video backgrounds, and responsive layouts.

The main goal of this project is to create and experiment with common website components that can be adapted and reused in future web development projects.

## Technologies Used

- **HTML5** — Page structure and semantic elements.
- **CSS3** — Styling, transitions, animations, and responsive layouts.
- **JavaScript** — Interactive functionality and event handling.
- **jQuery** — DOM manipulation, animations, and user interactions.
- **jQuery Cycle Plugin** — Automatic image slideshow.
- **Three.js** — 3D graphics library used by Vanta.js.
- **Vanta.js** — Animated background effects.
- **Particles.js** — Interactive particle animations.
- **SVG** — Scalable vector graphics and animations.
- **Google Maps Embed** — Integration of interactive maps.

## Features

### 1. Responsive Navigation Menu

- Dropdown navigation menu with animated submenus.
- Smooth slide-down and slide-up effects.
- Interactive logo animations.
- Logo transformations based on scrolling direction.
- Responsive hamburger menu for mobile devices.
- Expandable and collapsible mobile submenus.
- Automatic menu adjustment when resizing the browser window.

### 2. Parallax Scrolling Effect

- Background movement based on the user's scroll position.
- Smooth visual depth effect.
- Background image overlays.
- Responsive text positioning.

### 3. Animated Headers

Four different header designs demonstrating various visual effects:

**Header 1 — Background Image and Text Effects**

- Full-screen background image.
- Large decorative typography.
- CSS blend modes and text shadows.

**Header 2 — Animated Text Background**

- Animated background image inside text.
- CSS background clipping.
- Continuous animation using CSS keyframes.

**Header 3 — Vanta.js Animation**

- Animated network background using Vanta.NET.
- Interactive mouse and touch controls.
- Custom colors and animation settings.

**Header 4 — Particles.js Animation**

- Animated particle background.
- External JSON configuration.
- Particle effects integrated into the header section.

### 4. Hover Effects

- Interactive image cards.
- Sliding text overlays.
- Smooth CSS transitions.
- Image transformations on hover.

### 5. SVG Graphics and Animations

Examples of different SVG elements and effects:

- Rectangles.
- Circles.
- Ellipses.
- Polygons.
- Lines and polylines.
- Animated SVG paths.
- Text positioned along SVG paths.
- Image clipping using SVG shapes.
- Hover-triggered drawing animations.

### 6. Image Galleries

Three different image gallery implementations.

**Gallery 1 — Thumbnail Gallery**

- Main image preview.
- Clickable image thumbnails.
- Smooth fade transitions.
- Selected thumbnail highlighting.
- Expandable and collapsible gallery.

**Gallery 2 — Image Slider**

- Previous and next navigation buttons.
- Manual image switching.
- Continuous navigation between the first and last images.
- Active image management.

**Gallery 3 — Automatic Slideshow**

- Automatic image transitions.
- Fade animation.
- Configurable slideshow speed.
- Pause on mouse hover.
- Resume on mouse leave.
- Responsive image dimensions.

### 7. Video Components

**HTML5 Video Player**

- Embedded video playback.
- Native video controls.
- Support for multiple video formats.

**Video Background**

- Autoplay video.
- Muted playback.
- Continuous looping.
- Text content displayed over the video.

### 8. Google Maps Integration

- Embedded Google Maps.
- Different layouts for desktop and mobile devices.
- Responsive contact sections.
- Phone links adapted for mobile devices.
- Social media icons.

### 9. Responsive Design

- CSS media queries.
- Flexible layouts using Flexbox.
- Adaptive navigation.
- Responsive galleries and images.


### 2. Open the Project

Navigate to the project directory:

```bash
cd REPOSITORY-NAME
```
